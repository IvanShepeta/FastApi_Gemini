## ✨ Features

### 🎯 Core Features
- **🤖 Google Gemini AI Integration** - Powered by Google's latest Gemini AI model
- **🔐 User Authentication** - Secure JWT-based authentication system
- **💬 Chat History** - Persistent conversation storage with SQLite
- **🎨 Modern UI** - Beautiful, responsive interface with dark mode support
- **⚡ Real-time Chat** - Instant AI responses with typing indicators
- **📊 User Statistics** - Track your messages and chat sessions

### 🛠️ Technical Features
- **RESTful API** - Clean, documented API endpoints
- **Database ORM** - SQLAlchemy for robust database operations
- **CORS Support** - Cross-origin resource sharing enabled
- **Password Hashing** - Secure password storage with bcrypt
- **Token-based Auth** - JWT tokens with configurable expiration
- **Error Handling** - Comprehensive error handling and validation
